## Environment

ALWAYS use this python binary directly — do NOT use `conda run` (it buffers stdout, logs appear empty):

    /datadrive/conda/envs/unlearning/bin/python

Or activate first:

    source /datadrive/conda/etc/profile.d/conda.sh && conda activate unlearning

Flash Attention note: the `unlearning` env does NOT have flash_attn installed.
Always pass `model.model_args.attn_implementation=sdpa` to all train and eval commands.
Using `flash_attention_2` will fail silently or OOM.

Also always set:

    export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True

## What Was Done

Results are collected by:
1. Running training via scripts/run_muse_news_baselines.sh (or manually)
2. Running eval via src/eval.py pointing to the saved model
3. Reading results from saves/eval/<task_name>/MUSE_EVAL.json
4. Updating reports/muse_news.md by hand

The eval command template used for all baselines:

    python src/eval.py \
        experiment=eval/muse/default.yaml \
        data_split=News \
        task_name=<TASK_NAME> \
        model=Llama-2-7b-hf \
        model.model_args.pretrained_model_name_or_path=saves/unlearn/<SAVE_DIR> \
        model.model_args.attn_implementation=sdpa \
        retain_logs_path=saves/eval/muse_Llama-2-7b-hf_News_retrain/MUSE_EVAL.json

Results are in: saves/eval/<task_name>/MUSE_EVAL.json
Key metrics: forget_knowmem_ROUGE, forget_verbmem_ROUGE, retain_knowmem_ROUGE,
             extraction_strength, privleak

Train time: read from saves/unlearn/<SAVE_DIR>/trainer_state.json -> train_runtime (seconds)
