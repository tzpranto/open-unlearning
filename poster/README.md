# BLADE poster (EMNLP 2026)

A DIN A0 portrait research poster built with LaTeX beamer + `beamerposter`. It uses a Penn State theme: solid Beaver Blue, no gradients, Roboto and Roboto Slab fonts.

## Build

```bash
latexmk blade-poster.tex      # XeLaTeX + biber, configured in .latexmkrc
```

You need TeX Live with XeLaTeX and biber. The fonts (Roboto, Roboto Slab, Fira Mono) come with TeX Live. On Overleaf, set the compiler to **XeLaTeX**.

The plot PDFs are generated by Python scripts:

```bash
python poster/scripts/fig_stress.py       # -> figures/fig_stress.pdf
python poster/scripts/fig_benchmarks.py   # -> figures/fig_benchmarks.pdf
```

## Where things are

| Path | What it holds | Edit it when you want to change... |
|---|---|---|
| `blade-poster.tex` | Paper size, title/authors, and **all poster content**, laid out as rows (`Row 1` ... `Row 6`) | the text, the layout, column widths |
| `beamerthemePSUPoster.sty` | Header (logos + title), footer strip, outer blocks: `psublock`, `psufinalblock`, `plainblock`, `tldrbox` | header height, logos, block style |
| `beamercolorthemepsu.sty` | Color palette (`psu-beaver`, `psu-navy`, `psu-pugh`, `psu-pink`, tints) | the colors |
| `preamble/packages.tex` | Packages and fonts | fonts, extra packages |
| `preamble/bibliography.tex` | Compact biblatex style (first author, title, year) | how references look |
| `preamble/macros.tex` | Paper notation (`\method`, `\Loss`, `\Dforget`, ...) | your own notation |
| `preamble/boxes.tex` | Inner boxes: `probcard`, `compblock`, `benchtile`, `takeaway`, `\chip`, `\bignum`, `\circnum`, `\fixtag` | small components |
| `figs/` | TikZ diagrams, one per file, pulled in with `\input{figs/...}` | diagrams |
| `figures/` | Plot PDFs, pulled in with `\includegraphics` | plots |
| `scripts/` | Python scripts that write the plot PDFs in `figures/` | plot data and style |
| `logos/` | Header logos (normal and white "reversed" versions) | logos |
| `references.bib` | Bibliography entries | references |

### How the content is laid out

The whole poster is one beamer frame. The 98%-wide content column holds **rows**. Each row is a `columns` environment with 2–3 `column`s, and each column holds a `psublock`:

```latex
% ======================= Row N: name =======================
\begin{columns}[T]
  \begin{column}{0.40\linewidth}
    \begin{psublock}[equal height group=rN]{Block title}
      ...
    \end{psublock}
  \end{column}
  \begin{column}{0.58\linewidth}
    \begin{psublock}[equal height group=rN]{Another block}
      ...
    \end{psublock}
  \end{column}
\end{columns}
```

- In each row the column widths should add up to about 0.98. The leftover space becomes the gaps between columns.
- Giving the blocks in a row the same `equal height group=rN` makes them equally tall.
- `psublock` takes any tcolorbox option in its optional argument. For example, the key-result block uses `colframe=psu-navy, colbacktitle=psu-navy, boxrule=5pt` to stand out.

## Using it as a template

1. **Copy** the `poster/` folder and rename `blade-poster.tex` (also update the comment in `.latexmkrc`).
2. **Title block:** edit `\title`, `\author` and `\institute` in the main file.
3. **Logos:** put your files in `logos/` and override them in the main file's preamble:
   ```latex
   \renewcommand{\posterlogoleft}{logos/my-university-reversed}
   \renewcommand{\posterlogoright}{logos/my-conference-reversed}
   ```
   Change the logo width with `\setlength{\psulogowidth}{...}` and the header height with `\setlength{\psuheaderheight}{...}`.
4. **Paper size / orientation / text scale:** use the `beamerposter` line in the main file (`size=a0`, `orientation=portrait`, `scale=1.2`).
5. **Colors:** change the hex values in `beamercolorthemepsu.sty`. Every other file uses the `psu-*` names, so the new colors apply everywhere.
6. **Notation:** replace `preamble/macros.tex` with your own.
7. **Content:** keep the row/column/`psublock` structure and replace what's inside. Delete what you don't need from `figs/`, `figures/` and `scripts/`.
8. **References:** replace `references.bib`. Only entries you cite with `\autocite{...}` show up in the reference row.
